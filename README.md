## About

I am a **full-stack developer focused on backend engineering** with **Java and Spring Boot**. I am building a deeper understanding of APIs, databases, distributed systems and software architecture while using **Next.js, React and TypeScript** to deliver complete web products.

I care about systems that are reliable, maintainable and designed with a clear purpose — from the business rules and data flow to the interface used by the final user.

- Based in Brazil, working toward international opportunities
- Focused on backend development and complete web systems
- Interested in clean architecture, performance and distributed systems
